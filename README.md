# Enterprise Blue Team Lab

Laboratorio personal de ciberseguridad defensiva en un entorno virtualizado de Active Directory.

**Estado:** proyecto en desarrollo. Las carpetas son plantillas; no acreditan prácticas completadas.

## Infraestructura prevista

Windows Server 2022, Windows 11 y Ubuntu en VMware. Ampliación prevista con Sysmon y Wazuh.
